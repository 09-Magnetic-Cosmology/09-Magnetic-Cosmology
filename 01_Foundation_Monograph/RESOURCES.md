## 🗂️ Organizing Your Files on Android

### Mobile App Access Tips

Using GitHub mobile app with `PGS09MC_*` naming convention:

1. **Search files**: Use app search to find all `PGS09MC_` files
2. **Upload organization**: 
   - Create clear folder structure first
   - Upload by topic/folder for organization
   - App will show file count and status
3. **Naming**: Always start with `PGS09MC_` for consistency

### File Upload Process (Android)

```
Mobile App → Add File → Upload Files → 
Select from device (OneDrive, Drive, Photos) → 
Name: PGS09MC_[TopicName]_[Description].[ext] → 
Select folder → Commit
```
